Biblioteca de fotos dos alimentos (opcional)

O app mostra, dentro de cada refeicao aberta, uma faixa de imagens dos alimentos (alimentos-visual.js). Sem foto, usa uma ilustracao
com a cor do grupo do alimento. Para usar uma foto de verdade num alimento:

1. Coloque o arquivo JPG nesta pasta (ideal: quadrado, 400x400, ate 60 KB).
2. Em manifest.json acrescente a linha "id": "arquivo.jpg", com o MESMO id das regras de alimentos-visual.js
   (por exemplo "arroz", "frango", "banana", "ovo", "queijo", "batatadoce"). Uma foto vale para todos os alimentos daquele id.
3. Publique. Nao precisa gerar app novo: o app das lojas le esta pasta no site.

Use so fotos com licenca que permita uso comercial (Unsplash, Pexels, Pixabay, ou fotos suas) e anote a origem em LICENCAS.txt.
Se a foto nao carregar (internet ruim), o app mostra o quadro "toque para recarregar".
